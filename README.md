# 컬럼명 한글화 프로젝트
영문 컬럼명을 기반으로 한글 속성명을 생성/변환한다. 

## 작업 단계 및 경로
1. 컬럼코멘트 기반 한글화
- 컬럼코멘트가 존재하는 컬럼을 대상으로 하는 작업이다. 컬럼코멘트를 기반으로 영문 컬럼명을 한글 속성명으로 변환한다.
- 경로: meta_ai_kor_comment
2. 영문+한글 매핑
- 일부 완성된 영문 컬럼명과 한글 속성명을 기준으로 단어 매핑 정보를 만든다.
    - [예시] ACHV: 달성, BRCD: 지점코드
- 경로: meta_ai_mapping
3. 컬럼코멘트 없는 컬럼 한글화
- 매핑 정보를 기반으로 컬럼명을 한글화한다. 매핑 정보가 부족한 경우 영문 약어의 함축적 의미를 최대한 유추하여 한글명을 생성한다. 이후 최종적으로 속성명에 어울리게 다듬는다.
- 경로: meta_ai_kor
